# Theme Hospital PL 0.2 beta

Nieoficjalne spolszczenie Theme Hospital ze Steam, działające z oryginalnym silnikiem i DOSBoxem. Podstawą jest polskie tłumaczenie CorsixTH autorstwa społeczności eXtragry.pl i GrajPoPolsku.

Pobierz **ThemeHospital-PL-0.2-beta-public.zip**, rozpakuj cały pakiet i uruchom `Sprawdz.cmd`, a następnie `Instaluj.cmd`. Jeśli masz roboczą wersję 0.1, wybierz `Aktualizuj.cmd`. Język gry w Steam pozostaw ustawiony na **English**.

Zgodność: **App ID 2229820, build 25682708**. Instalator wymaga własnej kopii gry. Wykonuje backup przed podmianą plików; deinstalator przywraca oryginały. Narzędzia nie zmieniają zapisów rozgrywki.

Wersja 0.2 uzupełnia i poprawia 123 wpisy, dodaje polskie nazwy trudności oraz usuwa znaczniki skrótów klawiszowych nieobsługiwane przez oryginalne menu.

Sprawdzono instalację i przywracanie plików, ładowanie szpitali 1–12 z polskimi odprawami oraz uruchomienie przez Steam. Nie jest to pełny test kampanii ani wszystkich okien. Wydanie pozostaje **beta**.

Autorzy tłumaczenia źródłowego: **Bemberg, BuTcHeR, Johnny, Machiner, mziab, spec0071 i twig**. W paczce zachowano ich noty MIT oraz licencje kodu CorsixTH. Adaptację, uzupełnienia i narzędzia przygotowano z pomocą OpenAI Codex.
